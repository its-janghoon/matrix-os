# Working in this repository

## Commit and pull-request attribution

Every commit and pull-request body ends with:

```
Co-Authored-By: its-janghoon <44862514+its-janghoon@users.noreply.github.com>
```

The address is the GitHub noreply form for that account, so the commit is
attributed without publishing an email anywhere.

Never put a model name, model identifier, or version string into a commit
message, a pull-request title or body, a code comment, or anything else that
lands in this repository. Those belong in chat and nowhere else.

## Prose

Short dashes, never long ones. That applies to commit messages, documentation
and code comments alike.
